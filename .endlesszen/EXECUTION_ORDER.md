# Execution order

This is navigation, not an independent queue. Read [STATE_AND_QUEUE](STATE_AND_QUEUE.md)
for current work and [PROJECT_MANIFEST](PROJECT_MANIFEST.md) for gates.

Foundation production → separate-run review/repair → permitted integration → next useful
handbook or tool unit. Any repair changes the candidate revision and invalidates judgments
that depended on the old bytes. Missing host qualification gates its dependent transitions;
it does not authorize invented evidence, forced writes or stopping the hourly scheduler.

# Project controls

These documents support maintenance; they are not required to read the handbook.

- [Manifest](PROJECT_MANIFEST.md): scope, authority, quality rules and adoption limits.
- [State and queue](STATE_AND_QUEUE.md): current work, recovery and next actions.
- [Execution order](EXECUTION_ORDER.md): a navigation view, not a second mutable queue.
- [Unit registry](UNIT_REGISTRY.csv): permanent semantic units and acceptance criteria.
- [Changelog](../CHANGELOG.md): meaningful changes to the deliverable.

GitHub issues own discussion and acceptance tasks; pull requests, checks and commits own
implementation evidence. No duplicate Google Drive project is established.

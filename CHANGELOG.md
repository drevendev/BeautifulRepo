# Changelog

## Community safety candidate — 2026-10-03

**BR-COMMUNITY-003** adds a practical guide that separates ordinary bugs, security
vulnerabilities and conduct complaints instead of routing all three through public issues.
It adds a security-policy draft template and a code-of-conduct adoption checklist that require
a real tested confidential route before publication, plus structural tests that prevent the
templates from masquerading as live BeautifulRepo policy.

Primary guidance was rechecked on 2026-10-03 against GitHub security/community documentation
and Open Source Guides. This candidate does not enable Private Vulnerability Reporting, create
a confidential mailbox or adopt a code of conduct.

## Initial foundation candidate — 2026-10-03

Added the reader-first front page, repository checklist, README guide and scaffold,
three source-bounded pattern studies, dated program guidance and contribution workflow.
Added a structured catalog, offline validator, deterministic view and negative tests.
Preserved the existing MIT LICENSE.

This is production evidence, not a claim of independent review or a released version.
The bootstrap issue owns its acceptance work; repository-native checks and merge state
remain the evidence for integration. Later semantic changes should name their affected
unit or issue rather than silently rewriting the original rationale.

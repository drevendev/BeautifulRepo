# First pattern studies

Observed on **2026-10-03**. These are bounded source inspections, not runtime tests,
rankings by popularity, visual certifications or endorsements of every upstream claim.
Blob identifiers record the inspected file contents; upstream default-branch links may move.
No upstream artwork, source code or substantial prose is copied into this collection.

## Devostasis: make the result inspectable

Source: [README](https://github.com/drevendev/devostasis/blob/master/README.md),
blob `d20eb2ba4b9ada56d5c7d9d67a1cc8048668eb96`; full README inspected.

**Observed:** a specific product promise, named dimensions, an inline text report,
an output-artifact table and explicit treatment of missing evidence.

**Adopt:** show a representative result and explain its limits. BeautifulRepo's checklist
uses separate findings rather than a single aesthetic or health score; the catalog tool
states exactly what it validates.

**How:** place the result before exhaustive reference material; distinguish “not checked”
from “missing”. **Defer:** a live Devostasis integration until installation, configuration
and output have actually been tested. Do not infer implementation behavior from its README.

## Hungry Crab: give research a recognizable workflow

Source: [README](https://github.com/drevendev/HungryCrab/blob/master/README.md),
blob `0753c334b6f39177224a1eac29cdbcad4d28ca87`; partial inspection of introduction,
terminology, installation, command walkthrough, configuration and miner descriptions.
The remaining README is not covered by this study.

**Observed:** a distinctive identity, a glossary, step-by-step commands and evidence-linked
transfer decisions. **Adopt:** every resource should say what it solves and how to use the
idea locally. Explain metaphors instead of expecting newcomers to know them.

**How:** attach a decision and caveat to each catalog card. **Defer:** automated ingestion,
license conclusions and issue serving until separately evaluated. A memorable identity is
inspiration, not permission to copy a mascot or execute a foreign repository.

## Gum: connect a demo to its source

Source: [README](https://github.com/charmbracelet/gum/blob/main/README.md),
blob `ed90af80689fc2e24bf08179f96613e390766838`; lines 1–130 inspected.

**Observed:** a demo linked to a script, a short tutorial, and installation alternatives
with less-common paths collapsed under details. **Adopt:** let readers move from result
to example source, and use progressive disclosure for secondary paths.

**How:** show one useful example before presenting the full option space. **Defer:** copying
media or assuming animated previews are accessible. These observations are based on README
source; visual rendering and assistive-technology behavior have not been tested.

## Selection rule for future studies

Choose varied project types, not just large star counts. Each study must name its source,
inspection scope, reusable pattern, local action, tradeoff and verification status.
Negative examples should describe a reproducible obstacle without disparaging maintainers.

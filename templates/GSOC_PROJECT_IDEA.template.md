# Open-source project idea — draft, not an application

> **Status: unapproved proposal.** This template does not enroll a repository in
> Google Summer of Code, establish a mentor, promise selection or authorize
> external applications. Replace every `REPLACE_WITH_...` field before publishing
> an ideas page. Remove this notice only when the resulting description is accurate.

## At a glance

- **Project:** REPLACE_WITH_PROJECT_TITLE
- **Source repository:** REPLACE_WITH_PUBLIC_REPOSITORY_URL
- **Program year:** REPLACE_WITH_YEAR_OR_YEAR_ROUND
- **Idea owner:** REPLACE_WITH_CONFIRMED_MAINTAINER_OR_UNASSIGNED
- **Mentor(s):** REPLACE_WITH_CONFIRMED_AVAILABLE_MENTOR_OR_UNASSIGNED
- **Proposed scope:** REPLACE_WITH_SIZE_AND_HOURS_AFTER_CHECKING_CURRENT_RULES
- **Difficulty:** REPLACE_WITH_EASY_INTERMEDIATE_HARD_OR_UNASSESSED
- **Prerequisites:** REPLACE_WITH_ACTUAL_LANGUAGE_TOOLS_AND_SKILLS

## The problem

Write two to five sentences explaining the user or maintainer problem, why it
matters, and what existing behavior demonstrates it. Link to a public issue
or source example. Do not write a full solution for an applicant to copy.

**Evidence:** REPLACE_WITH_PUBLIC_ISSUE_OR_REVISION_AND_OBSERVED_LIMITATION

## Expected outcomes

- **Core deliverable:** REPLACE_WITH_ONE_USABLE_CHANGE
- **Observable proof:** REPLACE_WITH_REPRODUCIBLE_COMMAND_AND_EXPECTED_RESULT
- **Regression check:** REPLACE_WITH_TEST_OR_FIXTURE_WITH_FAIL_BEFORE_PASS_AFTER
- **Documentation:** REPLACE_WITH_FIRST_USE_COMMAND_AND_KNOWN_LIMITS
- **Optional stretch:** REPLACE_WITH_SEPARATELY_SCOPED_EXTRA_OR_NONE

The core must be independently useful without the stretch goal. State the
expected behavior, not a guaranteed implementation approach.

## Boundaries and dependencies

- **Out of scope:** REPLACE_WITH_NON_GOALS
- **Dependencies:** REPLACE_WITH_EXISTING_APIS_DATA_OR_NONE
- **Risks and fallback:** REPLACE_WITH_RISK_AND_SMALLER_ACCEPTABLE_DELIVERABLE
- **Access:** REPLACE_WITH_PUBLIC_REPRODUCTION_DATA_OR_DISPOSABLE_FIXTURES
- **Secrets and licensing:** REPLACE_WITH_SOURCE_AND_ASSET_RIGHTS_CONSTRAINTS

No private repositories, credentials, paid services or unpublished test data
should be assumed accessible to an external contributor.

## First contribution and review path

1. **Read:** REPLACE_WITH_REAL_PUBLIC_SETUP_GUIDE
2. **Reproduce:** REPLACE_WITH_ONE_VERIFIED_READ_ONLY_FIRST_COMMAND
3. **Discuss:** REPLACE_WITH_EXISTING_PUBLIC_ISSUE_OR_DISCUSSION_ROUTE
4. **Propose:** REPLACE_WITH_NORMAL_PR_AND_TEST_INSTRUCTIONS

Do not create a fictional mentor inbox, review SLA or application route.

## Mentoring and AI-tool expectations

- **Mentor commitment:** REPLACE_WITH_CONFIRMED_REVIEW_AND_MEETING_CAPACITY
- **Backup/absence plan:** REPLACE_WITH_ACTUAL_BACKUP_OR_EXPLICIT_GAP
- **Communication:** REPLACE_WITH_EXISTING_APPROVED_CHANNEL
- **AI tooling policy:** REPLACE_WITH_EXPLICIT_ALLOWED_RESTRICTED_OR_UNDECIDED_POLICY
- **Disclosure/testing:** REPLACE_WITH_REQUIREMENTS_FOR_REVIEW_OF_GENERATED_WORK

If no mentor or clear AI policy is available, keep this as an internal draft,
not an advertised GSoC project. Contributors and mentors should agree on
milestones and adjust them together rather than treating the list as a contract.

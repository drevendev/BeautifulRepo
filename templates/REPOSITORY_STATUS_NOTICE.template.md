# Repository status notice — choose ONE state

Copy **only the blockquoted notice** from either PAUSED or PRE-ARCHIVE into
your repository's README, near its beginning. Do not copy this template's
headings, instructional comments or final guidance link. Remove every
`[placeholder]` and verify the displayed notice in its destination file.
Keep a link only if it resolves **from the destination README**, not from
this template's location inside BeautifulRepo.

## PAUSED — use while the repository is NOT archived

> **Maintenance paused since [YYYY-MM-DD].** [Project name] is not
> receiving routine maintenance or release updates. [State whether new
> issues/PRs are being considered, without promising responses.]
>
> **Last documented revision:** [full 40-character commit SHA].
> **Last verified first success:** [exact command + observed result,
> environment and date, OR "Not verified since [date]"].
>
> [State whether a real successor has explicitly accepted maintenance.
> If none, say no successor is confirmed.] [State only a verified support
> or confidential reporting route, or say none is confirmed and warn
> readers not to post sensitive material in public issues.]
>
> This repository has **not** been archived on GitHub.

## PRE-ARCHIVE — prepare while the repository is still writable

> **Maintenance ended [YYYY-MM-DD].** This repository is being
> prepared for GitHub archival. After the owner confirms archival,
> GitHub will make its issues, PRs and source read-only.
>
> **Last documented revision:** [full 40-character commit SHA].
> **Last verified first success:** [exact command + observed result,
> environment and date, OR "Not verified since [date]"].
>
> [Explain open issues/PRs and remaining limitations.] [Provide a
> successor URL only after verifying consent and maintenance status.]
> [State the actual, verified confidential reporting situation; never
> invent an address or invite security reports into public issues.]

After GitHub archival actually succeeds, confirm the archived flag on
the repository page. Because content becomes read-only, do not promise
to modify this notice afterwards. If a final post-archive edit is essential,
it requires an authorized unarchive/edit/archive cycle.

For context, consult BeautifulRepo's
[repository retirement guide](https://github.com/drevendev/BeautifulRepo/blob/master/guides/repository-retirement.md).
This reference is **outside the copyable notice**; omit it unless it genuinely
helps readers of the destination repository.

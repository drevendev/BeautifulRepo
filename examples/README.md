# Choose a working repository example

Start with the interaction a reader needs to complete. Every example is local and
small on purpose: it demonstrates a trustworthy first-success route, not a
production service, published package or scientific certification.

## A command someone can run

[CLI starter](cli-starter/README.md) counts a tiny checked-in CSV without displaying
its rows. Use it to document arguments, output, errors and distribution boundaries.
Pair it with the [CLI guide](../guides/cli-repositories.md).

## A function someone can call

[Library starter](library-starter/README.md) provides a checkout-only import and a
runnable demo. It is not published on PyPI. Use the
[library template](../templates/LIBRARY_README.template.md) to distinguish an actual
installation route from a source-only exercise.

## A result someone can reproduce

[Research/data starter](research-data-starter/README.md) sums six fabricated rows
into A=36, B=24 and total=60. Its fixture digest and input regressions support this
small result, not a scientific claim or third-party data license.

## An application someone can explore

[Pocket Board](application-starter/README.md) serves five invented tasks on
loopback. A native form filters All/Open/Done without JavaScript. The
[application template](../templates/APPLICATION_README.template.md) explains
lifecycle, visible behavior and data boundaries rather than promising deployment.

## A collection someone can trust

[Curated references](curated-starter/README.md) renders three primary-source
recommendations with use cases, limitations and dated checks. The
[collection template](../templates/CURATED_README.template.md) makes selection and
retirement criteria visible; stale metadata is not a broken-link verdict.

## Improve an existing first impression

The [offline audit walkthrough](repository-audit/README.md) fixes specific README
observations, without assigning a beauty score. The
[PocketDiff visual example](readme-visuals/README.md) illustrates evidence-first
presentation and text alternatives, not a released PocketDiff application.

Before adapting a starter, use the [first-success checklist](../checklists/first-success.md).
For commands, reproducible evidence and review handoff, use the
[maintenance workflow](../guides/maintenance-workflow.md).

# PocketDiff

> Fictional README first-screen specimen. PocketDiff is not a released or
> executable tool; the output below is illustrative, not a measured result.

**See exactly what changed between two CSV exports—locally, with no upload.**

A January export and a February export can look identical until a key changes.
PocketDiff imagines a compact `changes.csv` report: **18 changed** rows,
**2 added**, and **1 removed**. These numbers describe one invented sample,
not a speed, accuracy or feature claim.

### One illustrative command

```console
$ pocketdiff january.csv february.csv --output changes.csv
18 changed · 2 added · 1 removed
Wrote changes.csv
```

The imagined inputs use the **same key column**. There is no verified installation
or first-run procedure. For a functioning alternative, try the
[real Rowcount starter](../../cli-starter/README.md).
